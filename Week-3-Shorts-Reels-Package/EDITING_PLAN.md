# Week 3 Editing Plan

## Master Workflow

1. Create a 1080×1920 vertical sequence at 30 fps.
2. Import all footage, voiceovers, music, graphics, and reference frames.
3. Select a strong hook before building the rest of each edit.
4. Remove pauses and dead space aggressively while preserving natural delivery.
5. Build captions from the final voice track and correct every transcription error.
6. Use punch-in zooms to direct attention rather than as decoration.
7. Add speed ramps at action peaks or transitions; use smooth interpolation.
8. Align selected cuts and transitions with musical beats.
9. Apply consistent color correction across all clips.
10. Check captions against the 9:16 safe area and platform interface zones.
11. Add a concise CTA appropriate to each video's goal.
12. Export and watch each complete file before delivery.

## Short 01 — Quick Tip

**Editing rhythm:** fast opening, 2–4 second shots, one clear reveal.

**Caption treatment:** emphasize the key mistake and the corrected technique.

**Effects:** two or three controlled punch-ins and one speed ramp at the transition to the solution.

**CTA:** “Follow for more editing tips.”

## Short 02 — Before / After

**Editing rhythm:** immediate raw footage, rapid process montage, then longer final-result shot.

**Caption treatment:** “RAW” and “EDITED” comparison labels.

**Effects:** speed up repetitive editing actions and use a clean wipe/split-screen for the final comparison.

**CTA:** “Save this transformation for inspiration.”

## Short 03 — Fast Tutorial

**Editing rhythm:** outcome first, then three compact steps.

**Caption treatment:** numbered steps with one highlighted action per screen.

**Effects:** small punch-ins on controls/details and speed ramps between steps.

**CTA:** “Save this and try it yourself.”

## Thumbnail Workflow

1. Select a high-quality frame from each finished video.
2. Crop the subject to create a strong focal point.
3. Add a short headline of 2–5 words.
4. Keep typography, placement, and branding consistent across all three thumbnails.
5. Check readability at small size before exporting.
6. Export each thumbnail as a high-quality JPG or PNG.

## Final QA

- Verify every video is 15–60 seconds.
- Confirm 1080×1920 resolution and 9:16 framing.
- Check caption timing, spelling, and safe-area placement.
- Confirm music usage rights.
- Listen for clipping, sudden volume changes, and distracting effects.
- Verify speed ramps and zoom keyframes are smooth.
- Check thumbnail text at mobile viewing size.
- Ensure filenames clearly map each thumbnail to its video.
