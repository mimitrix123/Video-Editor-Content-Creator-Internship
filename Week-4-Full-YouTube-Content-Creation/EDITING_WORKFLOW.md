# Week 4 Editing Workflow

## 1. Pre-production

1. Define audience and video objective.
2. Finalise the script.
3. Prepare shot list and production schedule.
4. Collect licensed music, SFX, graphics, and stock footage.
5. Create project folders before importing media.

## 2. Media Organisation

Use bins/folders for:

- A-roll
- B-roll
- Screen recordings
- Voiceover
- Music
- Sound effects
- Graphics
- Thumbnails
- Exports

Rename important clips with descriptive names and keep original camera files untouched.

## 3. Rough Cut

- Place the strongest A-roll first.
- Follow the script and remove mistakes.
- Tighten pauses and repeated phrases.
- Establish a logical story before adding effects.

## 4. Fine Cut

- Add B-roll to support narration.
- Vary framing with controlled punch-ins.
- Use transitions only where they improve continuity.
- Add speed ramps selectively.
- Maintain visual rhythm without over-editing.

## 5. Audio

Suggested track layout:

- A1: dialogue
- A2: backup dialogue/VO
- A3: music
- A4: sound effects
- A5: room tone/ambience

Priorities:

1. Dialogue clarity.
2. Consistent dialogue level.
3. Music underneath dialogue.
4. Subtle, purposeful sound effects.
5. Avoid clipping and unwanted background noise.

## 6. Color

Basic correction order:

1. Exposure.
2. White balance.
3. Contrast.
4. Saturation.
5. Shot matching.
6. Optional creative look.

Do not use a creative grade to hide incorrect exposure or white balance.

## 7. Graphics

Use one consistent visual language for:

- Intro title.
- Section headings.
- Lower thirds.
- Key-point call-outs.
- Captions.
- Outro/end screen.

Keep important text inside safe areas, especially for vertical Shorts.

## 8. Intro / Outro

### Intro

Keep branding short and avoid delaying the main value proposition. The first seconds should communicate the video's benefit.

### Outro

Include:

- concise closing statement,
- subscribe prompt,
- next-video recommendation,
- consistent channel branding.

## 9. Shorts Workflow

For each Short:

1. Identify one strong idea.
2. Start with the result/problem in the first seconds.
3. Remove pauses aggressively.
4. Reframe to 9:16.
5. Add readable captions.
6. Add controlled zooms and speed ramps.
7. Use licensed/platform-cleared music.
8. End with a simple action such as follow, subscribe, or save.

## 10. Thumbnail Workflow

1. Select one strong frame or create a custom composition.
2. Identify one message.
3. Limit headline to a few words.
4. Create strong visual hierarchy.
5. Apply the same typography/branding across the series.
6. Check readability at phone size.
7. Export as JPG/PNG according to YouTube's current requirements.

## 11. SEO Workflow

- Research the viewer's search intent.
- Put the main topic naturally in the title.
- Write a useful description rather than keyword stuffing.
- Add chapters where they help navigation.
- Add accurate captions/subtitles.
- Use relevant tags when useful.
- Name project/export files descriptively.
- Make thumbnail and title work together without misleading the viewer.

## 12. Final QA

Before export:

- [ ] No missing media.
- [ ] No accidental black frames.
- [ ] No unwanted gaps.
- [ ] Dialogue is understandable.
- [ ] Music is not overpowering.
- [ ] Graphics are spelled correctly.
- [ ] Captions are synchronised.
- [ ] Color is consistent.
- [ ] Intro/outro work correctly.
- [ ] End screen elements are correctly placed.

After export:

- [ ] Watch the complete file.
- [ ] Check beginning, middle, and end.
- [ ] Check audio on headphones and speakers.
- [ ] Confirm resolution, frame rate, and aspect ratio.
- [ ] Confirm the final filename.
- [ ] Verify all footage/music/graphics have appropriate rights.
