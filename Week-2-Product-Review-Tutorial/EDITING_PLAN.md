# Week 2 Editing Plan

## Timeline

**00:00–00:12 — Hook**
- Open with the strongest result or most interesting product detail.
- Use fast cuts and a bold one-line hook.
- Start music immediately, then bring narration in cleanly.

**00:12–00:25 — Introduction**
- Product hero shot.
- Creator/channel title.
- One-sentence promise of what viewers will learn.

**00:25–00:55 — Setup / Unboxing**
- Wide shot → close-up → action detail.
- Narrate what is included and how setup works.
- Add concise labels for important items.

**00:55–01:35 — Key Features**
- Demonstrate features rather than only describing them.
- Use punch-in crops or motion graphics for details.
- Add call-outs beside the relevant product area.

**01:35–02:15 — Real-World Test**
- Show the product being used.
- Cut between wide context and detail shots.
- Use on-screen observations to reinforce the narration.

**02:15–02:40 — Pros & Cons**
- Use two simple graphic cards.
- Keep each point short enough to read immediately.

**02:40–02:50 — Verdict**
- Return to the strongest hero shot.
- State who the product is best suited for.
- Optional rating/value graphic.

**02:50–03:00 — Subscribe CTA**
- End card with creator/channel branding.
- “Subscribe for more reviews & tutorials.”
- Optional next-video placeholder.
- Fade music out.

## Post-Production Checklist

- [ ] Hook communicates value within first 15 seconds
- [ ] Voiceover is clean and intelligible
- [ ] B-roll covers jump cuts where appropriate
- [ ] Text call-outs are readable on mobile
- [ ] Color and exposure are consistent
- [ ] Music does not compete with narration
- [ ] No audio clipping
- [ ] CTA remains visible long enough to read
- [ ] Final runtime is approximately 3 minutes
- [ ] Export verified at 1080p
